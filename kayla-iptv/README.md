# Kayla IPTV (TV UI)

واجهة تلفزيون لتطبيق **Kayla IPTV** — شبكة قنوات كبيرة مناسبة للريموت، مع مشغّل HLS للبث التجريبي العام.

## التشغيل

```bash
cd kayla-iptv
npm install
npm run dev -- --host 0.0.0.0 --port 5174
```

على التلفزيون (نفس الشبكة): افتح `http://<IP-الجهاز>:5174`

## التحكم

| مفتاح | وظيفة |
| --- | --- |
| أسهم | تنقل بين القنوات |
| Enter / Space | تشغيل |
| Esc / Backspace | رجوع |

## ملاحظة

القنوات الحالية تستخدم **بث تجريبي عام** (Mux / Apple test streams) وليست قنوات تلفزيون حية. اربط مصدر محتوى مرخّص خاص بك للإنتاج.
