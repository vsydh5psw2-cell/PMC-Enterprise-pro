# Kayla IPTV

Marketing site for **Kayla IPTV** — a premium streaming brand landing page.

## Run locally

```bash
cd kayla-iptv
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Notes

This is a front-end marketing demo (plans, devices, brand). It does not ship live streams, playlists, or credentials — connect your own licensed content source separately.
